## Summary

Google スプレッドシートの数式が参照するセルを一覧し、↑↓で順に移動。シート横断・非表示シートにも対応。財務モデルの監査に。Ctrl+Shift+A で起動。

## Description

Scopion は、数式が読んでいるセルをすべて一覧し、キー一つずつでたどらせてくれる拡張機能です。

数式の入ったセルを選んで Ctrl+Shift+A（またはツールバーのアイコン）。セルの横に小さなパネルが開き、参照先がシート名・アドレス・現在の値（範囲なら合計）とともに並びます。↓ を押すとスプレッドシートの選択がその参照先へジャンプ。押し続ければ、シートをまたいで、非表示シートの中へ、名前付き範囲を通って、数式の流れをそのまま追えます。数式内の各参照は対応する行と同じ色で塗られるので、数式と一覧を一体として読めます。

財務モデルのために
• 起点行: 一覧は監査したセル自身から始まるので、最初の入力から ↑ で元の位置に戻れます。
• ドリルダウン: → でハイライト中のセルを新しい起点に。← または Backspace で戻る。たどった経路はブレッドクラムで表示され、クリックでその位置に戻れます。
• 空白入力を強く警告: 参照先が空のセルは、たいてい探していた間違いそのものです。
• 範囲の行はブロック全体を選択し、合計と件数を表示します。
• IMPORTRANGE の行はリンク元のスプレッドシートを開きます。
• OFFSET・INDEX・INDIRECT はリテラルと単一セルの値から解決します。解決できないものは理由つきで「未解決」として表示され、黙って省かれることはありません。
• 非表示シートも通常どおりたどれます。ジャンプするとスプレッドシートがそのシートを表示状態にしますが、パネルを閉じるときに Scopion が再び非表示に戻します（Excel ファイルでは戻せないため、パネルが手動で非表示に戻すよう案内します）。

キー操作
↑ ↓ 参照先をたどる（選択も移動）· → 新しい起点 · ← / Backspace 戻る · Enter その場で閉じる · Esc / OK 開始位置に戻って閉じる。ショートカットが他の拡張機能と重なる場合は chrome://extensions/shortcuts で変更できます。

アクセスするもの、そして唯一の書き込み
Scopion は、あなたが起動したときだけ、開いているスプレッドシートを Google Sheets API で読み取ります（シート名、名前付き範囲、数式が指すセル）。行う変更は一種類だけ: たどるために表示状態にしたシートを再び非表示に戻すことです。サーバーは持たず、Google の API 以外のどこにもデータを保存・記録・送信しません。表示設定 3 つとパネルの最後の位置は Chrome プロファイル内に保存されます。詳細はプライバシーポリシーをご覧ください。

知っておくと便利
• スプレッドシートで開いた Excel ファイル (.xlsx) には API データがありません。参照とジャンプは動作し、値は — と表示され、たどった非表示シートは手動で戻すまで表示状態のままです。
• 参照元は Excel 版と同じく 1 階層です。深く見るにはドリルダウンしてください。参照先（依存セル）の追跡は行いません。
• パネルの表示は英語です。ストアページとインストール後の案内ページは日本語でも表示されます。

Scopion は、Excel の中で長年モデラーに使われてきた数式監査ツールを、Google スプレッドシート向けに作り直したものです。
